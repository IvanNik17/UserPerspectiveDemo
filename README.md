# UserPerspectiveDemo
A basic example of utilizing face detection and tracking to create. The demo is not a true Anamorphic Illusion because of lack of perspective change - for that you can check out the demo connected to the repo here - https://github.com/ShinyWindow/Anamorphic-Illusion
For the demo you need OpenTrack installed - https://github.com/opentrack/opentrack and configured to output to UDP over network with - IP address 127.0.0.1 and Port 4242.

In the Options -> Output -> you need to set pitch, x and z to Pre-inverse and the Input as NeuralNet Tracker
